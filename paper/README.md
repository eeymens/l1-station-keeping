# Paper

`main.tex` is the manuscript. Every number and table in it is generated by
`scripts/11_paper_assets.py` from the raw results in `experiments/` and
written to `generated/` — nothing is typed in by hand.

Build from the repository root:

```bash
make paper          # runs scripts/11_paper_assets.py, then latexmk -> paper/main.pdf
```

**Overleaf.** Upload `main.tex`, `references.bib`, the `generated/` folder and
the figures used by the paper into a `figures/` folder next to `main.tex`
(`l1_escape.png`, `lqr_pareto.png`, `paper_seed_study.pdf`, `paper_robustness.pdf`).
`\graphicspath` looks in both `../figures/` and `figures/`, so the same source
compiles locally and on Overleaf. Compiler: pdfLaTeX.
